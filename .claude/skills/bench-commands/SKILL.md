# Bench commands

OpenConsult is a research and education prototype. It is not a medical device. It must never be used with real patients or real patient data. Every case and recording a bench reads is acted or scripted.

The rules on where a bench may write and where a key is read are in CLAUDE.md, under Running it. A stage that adds or changes a bench command changes its line here.

    uv run openconsult-bench wordcheck --cases DIR --out DIR --v1-calls FILE... --v1-prompts DIR  # no model; DIR holds v1's two prompt files, proven against the calls' own record
    uv run openconsult-bench run --cases DIR --out DIR --digest ID [--kind ollama|llamacpp|vllm|deepinfra|claude --engine URL --model NAME --data-folder DIR --key-folder DIR --effort low|medium|high] [--together] [--background] [--chains A1 ...]   # --together is the app's own pass; --background is 7b's arm, each pass with the case's earlier note as the block; --effort is the claude kind's alone, the service's own setting, its default when not given; the two cloud kinds are the bench's alone, each to its service's own address over https with its key (DEEPINFRA_API_KEY, ANTHROPIC_API_KEY) read from the key folder's .env inside the process, the chain written apart and the run stopped when the service refuses the key or the credit: deepinfra (9a2) sends the chat engine's request; claude (9d) the Messages API request with no temperature, the form sent with every object closed and maxItems off while the door checks the whole form, the rate kept by the service's headers; letters and guideline take the same kind and folder
    uv run openconsult-bench score --out DIR | --replies FILE | background-score --with DIR --without DIR --write DIR     # the marks of one arm; 7b's four marks from its two arms' stored results; figures --public engine-bench: the public report's figures, no engine
    uv run openconsult-bench speech-run --recordings DIR --arm NAME --data-folder DIR --out DIR [--recording NAME ... --key-folder DIR] [--started-file F --pause-at-stop DIR]   # a banked recording through an arm, as if live; speech-fetch --data-folder DIR first for the tied pair's model; a cloud arm reads its key from the key folder's .env inside the process; speech-selftest --choice NAME --data-folder DIR --key-folder DIR is a cloud choice's self-test with the key kept apart; speech-upload --service speechmatics|assemblyai --key-folder DIR --out DIR --recordings DIR [--recording NAME ...] | --gate | --held DIR ... (5e) sends a recording whole to the service's EU address under a plain name, reads the result, deletes it and proves it gone (exit 10 when not proven)
    uv run openconsult-bench speech-voice --out DIR --recordings DIR --data-folder DIR [--voice NAME] | speech-voice-cut --out DIR --recordings DIR --scripts DIR --write DIR | speech-calls --out DIR --recordings DIR --scripts DIR --data-folder DIR --job label_check_app|label_check|label_check_parts|drug_name|note|script_note [--round N] [--engine URL --kind ollama|llamacpp|vllm|claude --model NAME --key-folder DIR]   # the doctor's voice learnt once, or cut from a recording's own stored page and never used on that recording (5e); the language model on the stored pages, reading the app's own prompt files, the label check as the app sent it until 6c, on the joined lines the app reads now, and in parts (6c: each page cut in two with consult/joined.py, half rounded up, 10 lines carried); the claude kind is the bench's alone, its key read from the key folder's .env inside the process; both under DIR; speech-calls needs --data-folder apart from --out
    uv run openconsult-bench speech-drugs --month YYYYMM --from URL --out DIR   # the UK drug list from one month of the prescribing data; the one fetch from outside
    uv run openconsult-bench speech-score --out DIR --recordings DIR --scripts DIR --marks FILE --write DIR [--key-facts FILE --drug-list FILE --counting]   | speech-stop-marks --local DIR [--parts DIR --cloud DIR --whole DIR --second-round] --recordings DIR --scripts DIR --marks FILE --write DIR   # the tables, from the stored results alone; --counting says the figures count and adds the tables of 5e; speech-stop-marks (6c): the who-spoke check whole and in parts and the drug-name marks, P1 and P2, and H1, H2, D1 to D3 for a cloud model (a cloud folder with the drug-name call alone gives D1 to D3 alone; --second-round, 6d, sets that call asked again with --round 2 beside the first), every stored reply judged afresh by the rule of 15.10 ruling 24 and never by the labels stored with it
    uv run openconsult-bench letters --cases DIR --out DIR --digest ID [--kind ollama|llamacpp|vllm --engine URL --data-folder DIR --letter CASE=SPECIALTY ... --case NAME ... --chains A1 ...]; letters-score --out DIR --write DIR   # 8a: the list call and the letters on the approved notes of DIR, 13 chains, through the door with the app's own numbering, frames and check; the five marks from the stored results alone
    uv run openconsult-bench guideline-load --folder DIR --publisher NAME --data-folder DIR --statement-accepted [--where card|processor --into-my-data-folder]; guideline --queries FILE --out DIR --data-folder DIR --age N --sex F|M [--queries-sha256 HASH --kind vllm --engine URL --digest ID --reranker --reranker-where card|processor --search-only --query ID ... --chains A1 ...]; guideline-score --without DIR [--with DIR] --write DIR; shared-install --data-folder DIR   # 8b: every file of DIR through the app's own loader into a data folder's corpus (a bench folder; your own only by its path with the flag, and with the app closed; never the repo), the publisher given here only; each query once through the app's search and 13 chains through its summary call; G1 to G3 an arm, R1 to R3 between the arms, from the stored results alone; 5d's install, the same code as install-guidelines without the reranker
    uv run openconsult-bench teaching --material DIR --out DIR --arm NAME --kind vllm|ollama|claude --engine URL [--model NAME --digest ID --key-folder DIR --data-folder DIR] [--trial] [--part actor|examination|feedback|writer ... --rounds 2 --case ID ... --max-dollars 3]; teaching-score --arm NAME=DIR ... --material DIR --write DIR   # 10a: the four jobs of teaching on the private bench material of DIR (case_*.json and writer_runs.json; read, never changed), through the door with the app's own frames and forms; --trial first, in every --out folder: four calls, one of each job, and no bench starts in a folder whose trial did not hold; then the actor line by line on the material's reference replies, the examination, the feedback (--rounds each) and the writer's fresh cases (once, each with its own seed); one file a call under DIR/results, never written over, so the same command carries a stopped bench on and sends no call twice; the claude kind stops when its cost passes --max-dollars at the two prices the bench names, and after three refusals for rate in a row (exit 11); teaching-score: the hard marks code can count (four, five, the counted part of six), the counts, the seconds, the tokens and the proof of the words, from the stored files alone; hard marks one to three are read, not counted
    uv run openconsult-bench shared-search --out DIR --embedding first|second --where card|processor [--data-folder DIR --searches N | --until FILE --after FILE --load-only]; shared-index ...; shared-watch --out DIR --until FILE [--private URL --vllm URL]; shared-judge --run DIR --write DIR [--card FILE --apps FILE] | --ask-wayround   # the searches every 5 s; the side reading; the readings beside a setup; the four lines and the tables, from the stored results alone
